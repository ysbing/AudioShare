# id-id

## Nama tampilan

```
AudioShare
```

## Deskripsi

```
AudioShare mengalirkan suara dari Windows atau Mac Anda ke ponsel Android melalui USB atau Wi-Fi. Tidak ada yang perlu dipasang di ponsel, dan root juga tidak diperlukan.

Komputer merekam suaranya; ponsel yang memutarannya.

Mulai
1. Pasang AudioShare di komputer Anda dan jalankan.
2. Aktifkan USB debugging di ponsel, atau pasangkan dengan ADB melalui Wi-Fi, lalu hubungkan.
3. Tekan Hubungkan saat ponsel muncul di daftar.

Semua yang sedang diputar di komputer Anda sekarang keluar dari ponsel.

• Perekaman audio sistem — 48 kHz stereo di Windows (loopback WASAPI) dan di macOS 13 atau lebih baru (ScreenCaptureKit).
• Tidak perlu memasang apa pun di ponsel — ADB dan server pemutaran sudah disertakan dalam AudioShare.
• USB dan ADB melalui Wi-Fi, dengan sambungan ulang otomatis ke perangkat terakhir yang dipakai.
• Privasi didahulukan — tidak ada yang direkam, disimpan, atau diunggah.

Kebutuhan
• Windows 10/11 x64 dengan driver ADB yang berfungsi, atau macOS 13 atau lebih baru.
• Ponsel atau tablet Android dengan USB debugging aktif. Android 6.0 atau lebih baru.

AudioShare tersedia dalam 28 bahasa: Inggris, Tionghoa Sederhana, Tionghoa Tradisional, Spanyol, Portugis, Rusia, Jepang, Korea, Jerman, Prancis, Italia, Hindi, Arab, Turki, Vietnam, Indonesia, Polandia, Thai, Belanda, Swedia, Ceko, Ibrani, Ukraina, Rumania, Yunani, Hongaria, Denmark, dan Finlandia.
```

## Yang baru

```
• Antarmuka kini tersedia dalam 28 bahasa, termasuk Tionghoa Tradisional, Arab, dan Ibrani.
• Pemilih bahasa kini dapat dicari dan dapat mengikuti bahasa yang dilaporkan sistem.
• Tata letak kini menyesuaikan ukuran jendela, bukan lagi mengasumsikan ukuran tetap.
```
