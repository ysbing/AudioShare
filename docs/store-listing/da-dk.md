# da-dk

## Vist navn

```
AudioShare
```

## Beskrivelse

```
AudioShare sender lyden fra din Windows- eller Mac-computer til en Android-telefon via USB eller Wi-Fi. Der skal ikke installeres noget på telefonen, og root er ikke nødvendigt.

Computeren optager lyden; telefonen afspiller den.

Sådan kommer du i gang
1. Installér AudioShare på din computer, og start det.
2. Slå USB-fejlfinding til på telefonen, eller par den med ADB over Wi-Fi, og forbind den derefter.
3. Tryk på Forbind, når telefonen vises på listen.

Alt, der afspilles på din computer, kommer nu ud af telefonen.

• Optagelse af systemlyd — 48 kHz stereo på Windows (WASAPI loopback) og på macOS 13 eller nyere (ScreenCaptureKit).
• Intet skal installeres på telefonen — ADB og afspilningsserveren følger med i AudioShare.
• USB og ADB over Wi-Fi, med automatisk genoprettelse af forbindelsen til den seneste enhed.
• Privatliv først — intet optages, gemmes eller uploades.

Krav
• Windows 10/11 x64 med fungerende ADB-drivere, eller macOS 13 eller nyere.
• En Android-telefon eller -tablet med USB-fejlfinding slået til. Android 6.0 eller nyere.

AudioShare fås på 28 sprog: engelsk, forenklet kinesisk, traditionelt kinesisk, spansk, portugisisk, russisk, japansk, koreansk, tysk, fransk, italiensk, hindi, arabisk, tyrkisk, vietnamesisk, indonesisk, polsk, thai, hollandsk, svensk, tjekkisk, hebraisk, ukrainsk, rumænsk, græsk, ungarsk, dansk og finsk.
```

## Hvad er nyt

```
• Brugerfladen findes nu på 28 sprog, heriblandt traditionelt kinesisk, arabisk og hebraisk.
• Sprogvælgeren kan nu søges i og kan følge det sprog, systemet melder.
• Layoutet skalerer nu med vinduet i stedet for at gå ud fra en fast størrelse.
```
