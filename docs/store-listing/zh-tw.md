# zh-tw

## 顯示名稱

```
AudioShare
```

## 描述

```
AudioShare 把 Windows 或 Mac 上的系統聲音透過 USB 或 Wi-Fi 傳到 Android 手機。手機端不用安裝任何 App，也不需要 root。

電腦負責擷取聲音，手機負責播放。

快速上手
1. 在電腦上安裝並啟動 AudioShare。
2. 在手機上開啟 USB 偵錯，或用 ADB 配對 Wi-Fi，然後連接手機。
3. 手機出現在清單裡之後，按下「連線」。

電腦上正在播放的一切，現在都從手機裡放出來。

• 系統音訊擷取 —— Windows 上透過 WASAPI loopback 擷取 48 kHz 立體聲，macOS 13 以上透過 ScreenCaptureKit 擷取。
• 手機端無需安裝任何 App —— ADB 與播放伺服器都打包在 AudioShare 裡。
• 支援 USB 與 ADB over Wi-Fi，並會自動重新連線到上次使用的裝置。
• 隱私優先 —— 不錄音、不儲存、不上傳。

執行需求
• Windows 10/11 x64 且 ADB 驅動程式正常，或 macOS 13 以上。
• 一台開啟了 USB 偵錯的 Android 手機或平板，Android 6.0 以上。

AudioShare 支援 28 種語言：英語、簡體中文、繁體中文、西班牙語、葡萄牙語、俄語、日語、韓語、德語、法語、義大利語、印地語、阿拉伯語、土耳其語、越南語、印尼語、波蘭語、泰語、荷蘭語、瑞典語、捷克語、希伯來語、烏克蘭語、羅馬尼亞語、希臘語、匈牙利語、丹麥語和芬蘭語。
```
