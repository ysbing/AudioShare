## คำอธิบาย

```
AudioShare ส่งเสียงระบบจาก Windows หรือ Mac ของคุณไปยังโทรศัพท์ Android ผ่าน USB หรือ Wi-Fi ไม่ต้องติดตั้งแอปใด ๆ บนโทรศัพท์ และไม่ต้องใช้ root

คอมพิวเตอร์เป็นผู้จับเสียง ส่วนโทรศัพท์เป็นผู้เล่นเสียง

เริ่มต้นอย่างไร
1. ติดตั้ง AudioShare บนเครื่องคอมพิวเตอร์แล้วเปิดใช้งาน
2. เปิดใช้งาน USB debugging บนโทรศัพท์ หรือจับคู่ผ่าน ADB บน Wi-Fi แล้วเสียบเข้า
3. กด เชื่อมต่อ เมื่อโทรศัพท์ปรากฏในรายการ

ทุกอย่างที่กำลังเล่นอยู่บนคอมพิวเตอร์ของคุณจะดังออกมาจากโทรศัพท์

• การจับเสียงระบบ — สเตอริโอ 48 kHz บน Windows (WASAPI loopback) และบน macOS 13 ขึ้นไป (ScreenCaptureKit)
• ไม่ต้องติดตั้งอะไรบนโทรศัพท์ — ADB และเซิร์ฟเวอร์เล่นเสียงมาพร้อมกันใน AudioShare
• รองรับ USB และ ADB บน Wi-Fi พร้อมเชื่อมต่อกลับอุปกรณ์เดิมโดยอัตโนมัติ
• ให้ความสำคัญกับความเป็นส่วนตัว — ไม่มีการบันทึก เก็บ หรืออัปโหลดเสียงใด ๆ

ความต้องการ
• Windows 10/11 x64 ที่มีไดรเวอร์ ADB ทำงานได้ หรือ macOS 13 ขึ้นไป
• โทรศัพท์หรือแท็บเล็ต Android ที่เปิดใช้งาน USB debugging ไว้ Android 6.0 ขึ้นไป

AudioShare รองรับ 28 ภาษา: อังกฤษ จีนตัวย่อ จีนตัวเต็ม สเปน โปรตุเกส รัสเซีย ญี่ปุ่น เกาหลี เยอรมัน ฝรั่งเศส อิตาลี ฮินดี อาหรับ ตุรกี เวียดนาม อินโดนีเซีย โปแลนด์ ไทย ดัตช์ สวีเดน เช็ก ฮีบรู ยูเครน โรมาเนีย กรีก ฮังกรี ดันมาร์ก และฟินแลนด์
```

## มีอะไรใหม่

```
• หน้าจอใช้งานมี 28 ภาษาแล้ว รวมถึงจีนตัวเต็ม อาหรับ และฮีบรู
• เมนูเลือกภาษาใช้ค้นหาได้ และเลือกตามภาษาที่ระบบรายงานได้
• เลย์เอาต์ปรับขนาดตามหน้าต่างแทนที่จะกำหนดขนาดคงที่
```
