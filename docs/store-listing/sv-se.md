# sv-se

## Visningsnamn

```
AudioShare
```

## Beskrivning

```
AudioShare skickar ljudet från din Windows- eller Mac-dator till en Android-telefon via USB eller Wi-Fi. Inget behöver installeras på telefonen, och root krävs inte.

Datorn fångar upp ljudet; telefonen spelar upp det.

Kom igång
1. Installera AudioShare på datorn och starta det.
2. Aktivera USB-felsökning på telefonen, eller para den via ADB över Wi-Fi, och anslut den.
3. Tryck på Anslut när telefonen visas i listan.

Allt som spelas upp på din dator kommer nu ut ur telefonen.

• Systemljudsupptagning — 48 kHz stereo i Windows (WASAPI loopback) och i macOS 13 eller senare (ScreenCaptureKit).
• Inget att installera på telefonen — ADB och uppspelningsservern finns inbyggd i AudioShare.
• USB och ADB över Wi-Fi, med automatisk återanslutning till den senast använda enheten.
• Integritet först — ingenting spelas in, lagras eller laddas upp.

Krav
• Windows 10/11 x64 med fungerande ADB-drivrutiner, eller macOS 13 eller senare.
• En Android-telefon eller -surfplatta med USB-felsökning aktiverad. Android 6.0 eller senare.

AudioShare finns på 28 språk: engelska, förenklad kinesiska, traditionell kinesiska, spanska, portugisiska, ryska, japanska, koreanska, tyska, franska, italienska, hindi, arabiska, turkiska, vietnamesiska, indonesiska, polska, thai, nederländska, svenska, tjeckiska, hebreiska, ukrainska, rumänska, grekiska, ungerska, danska och finska.
```
