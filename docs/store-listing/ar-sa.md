# ar-sa

## الاسم المعروض

```
AudioShare
```

## الوصف

```
ينقل AudioShare صوت جهاز Windows أو Mac إلى هاتف Android عبر USB أو Wi-Fi. لا حاجة إلى تثبيت أي شيء على الهاتف، ولا إلى صلاحيات root.

الجهاز التقني يلتقط الصوت، والهاتف هو من يشغّله.

البدء
1. ثبّت AudioShare على حاسوبك وابدأه.
2. فعّل تصحيح أخطاء USB على الهاتف، أو اقرنه عبر ADB على Wi-Fi، ثم وصّله.
3. اضغط "اتصال" عندما يظهر الهاتف في القائمة.

كل ما يُشغَّل على حاسوبك صار يُسمع الآن من الهاتف.

• التقاط صوت النظام: 48 كيلوهرتز ستيريو على Windows (حلقة WASAPI) وعلى macOS 13 فما فوق (ScreenCaptureKit).
• لا شيء يُثبَّت على الهاتف: ADB وخادم التشغيل يأتيان داخل AudioShare.
• USB و ADB عبر Wi-Fi، مع إعادة اتصال تلقائي بآخر جهاز استخدمته.
• الخصوصية أولًا: لا يُسجَّل شيء ولا يُحفظ ولا يُرفع.

المتطلبات
• Windows 10/11 x64 مع تعريفات ADB عاملة، أو macOS 13 فما فوق.
• هاتف أو جهاز لوحي بنظام Android مع تفعيل تصحيح أخطاء USB. Android 6.0 فما فوق.

يتوفر AudioShare بـ 28 لغة: الإنجليزية، الصينية المبسطة، الصينية التقليدية، الإسبانية، البرتغالية، الروسية، اليابانية، الكورية، الألمانية، الفرنسية، الإيطالية، الهندية، العربية، التركية، الفيتنامية، الإندونيسية، البولندية، التايلاندية، الهولندية، السويدية، التشيكية، العبرية، الأوكرانية، الرومانية، اليونانية، المجرية، الدنماركية، الفنلندية.
```

## ما الجديد

```
• أصبحت الواجهة متاحة الآن بـ 28 لغة، منها الصينية التقليدية والعربية والعبرية.
• أصبحت قائمة اختيار اللغة قابلة للبحث، ويمكنها اتباع اللغة التي يبلّغ عنها النظام.
• أصبح التخطيط يتكيّف مع النافذة بدل افتراض حجم ثابت.
```
