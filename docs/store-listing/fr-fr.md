# fr-fr

## Nom

```
AudioShare
```

## Description

```
AudioShare transmet le son de votre PC Windows ou Mac vers un téléphone Android en USB ou en Wi-Fi. Rien ne s'installe sur le téléphone, et le root n'est pas nécessaire.

L'ordinateur capte le son ; le téléphone le diffuse.

Pour commencer
1. Installez AudioShare sur votre PC et lancez-le.
2. Activez le débogage USB sur le téléphone, ou associez-le en ADB par Wi-Fi, puis branchez-le.
3. Appuyez sur Connecter lorsque le téléphone apparaît dans la liste.

Tout ce qui joue sur votre ordinateur sort maintenant par le téléphone.

• Capture du son du système — 48 kHz stéréo sous Windows (boucle WASAPI) et sous macOS 13 ou plus récent (ScreenCaptureKit).
• Rien à installer sur le téléphone — ADB et le serveur de lecture sont fournis dans AudioShare.
• USB et ADB par Wi-Fi, avec reconnexion automatique au dernier appareil utilisé.
• Privé par conception — rien n'est enregistré, stocké ni envoyé.

Configuration requise
• Windows 10/11 x64 avec des pilotes ADB fonctionnels, ou macOS 13 ou plus récent.
• Un téléphone ou une tablette Android avec le débogage USB activé. Android 6.0 ou plus récent.

AudioShare est disponible en 28 langues : anglais, chinois simplifié, chinois traditionnel, espagnol, portugais, russe, japonais, coréen, allemand, français, italien, hindi, arabe, turc, vietnamien, indonésien, polonais, thaï, néerlandais, suédois, tchèque, hébreu, ukrainien, roumain, grec, hongrois, danois et finnois.
```

## Nouveautés

```
• L'interface est désormais disponible en 28 langues, dont le chinois traditionnel, l'arabe et l'hébreu.
• Le sélecteur de langue peut désormais être recherché et suivre la langue signalée par le système.
• La mise en page s'adapte à la fenêtre au lieu de supposer une taille fixe.
```

## Fonctionnalités

```
• Capture du son système via la boucle WASAPI
• Connexion USB ou ADB via Wi-Fi
• Reconnexion automatique au dernier appareil utilisé
• Aucune application à installer sur le téléphone
• Interface disponible en 28 langues
```
