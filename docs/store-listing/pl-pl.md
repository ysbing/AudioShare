# pl-pl

## Nazwa wyświetlanej

```
AudioShare
```

## Opis

```
AudioShare przesyła dźwięk z komputera z systemem Windows lub Mac na telefon z Androidem przez USB lub Wi-Fi. Na telefonie nie trzeba nic instalować, a root nie jest potrzebny.

Komputer przechwytuje dźwięk; telefon go odtwarza.

Pierwsze kroki
1. Zainstaluj AudioShare na komputerze i uruchom go.
2. Włącz debugowanie USB na telefonie albo sparuj go przez ADB w Wi-Fi, a następnie podłącz.
3. Naciśnij Połącz, gdy telefon pojawi się na liście.

Wszystko, co gra na komputerze, słychać teraz z telefonu.

• Przechwytywanie dźwięku systemu — 48 kHz stereo w Windows (pętla WASAPI) i w macOS 13 lub nowszym (ScreenCaptureKit).
• Na telefonie nie trzeba nic instalować — ADB i serwer odtwarzania są już w AudioShare.
• USB oraz ADB przez Wi-Fi, z automatycznym łączeniem się z ostatnio używanym urządzeniem.
• Prywatność przede wszystkim — nic nie jest nagrywane, zapisywane ani wysyłane.

Wymagania
• Windows 10/11 x64 z działającymi sterownikami ADB albo macOS 13 lub nowszy.
• Telefon lub tablet z Androidem z włączonym debugowaniem USB. Android 6.0 lub nowszy.

AudioShare jest dostępny w 28 językach: angielski, uproszczony chiński, tradycyjny chiński, hiszpański, portugalski, rosyjski, japoński, koreański, niemiecki, francuski, włoski, hindi, arabski, turecki, wietnamski, indonezyjski, polski, tajski, niderlandzki, szwedzki, czeski, hebrajski, ukraiński, rumuński, grecki, węgierski, duński i fiński.
```

## Nowości

```
• Interfejs jest teraz dostępny w 28 językach, w tym w tradycyjnym chińskim, arabskim i hebrajskim.
• Wybór języka można teraz przeszukiwać i może on podążać za językiem zgłoszonym przez system.
• Układ skaluje się teraz z oknem, zamiast zakładać stały rozmiar.
```
