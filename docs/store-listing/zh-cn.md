# zh-cn

## 显示名称

```
AudioShare
```

## 描述

```
AudioShare 把 Windows 或 Mac 上的系统声音通过 USB 或 Wi-Fi 传到安卓手机。手机端不用装任何应用，也不需要 root。

电脑负责采集声音，手机负责播放。

快速上手
1. 在电脑上安装并启动 AudioShare。
2. 在手机上开启 USB 调试，或用 ADB 配对 Wi-Fi，然后连接手机。
3. 手机出现在列表里之后，点"连接"。

电脑上正在播放的一切，现在都从手机里放出来。

• 系统音频采集 —— Windows 上通过 WASAPI 回环采集 48 kHz 立体声，macOS 13 及以上通过 ScreenCaptureKit 采集。
• 手机端无需安装任何应用 —— ADB 和播放服务都打包在 AudioShare 里。
• 支持 USB 和 ADB over Wi-Fi，并会自动重连上次使用的设备。
• 隐私优先 —— 不录音、不存储、不上传。

运行要求
• Windows 10/11 x64 且 ADB 驱动正常，或 macOS 13 及以上。
• 一台开启了 USB 调试的安卓手机或平板，Android 6.0 及以上。

AudioShare 支持 28 种语言：英语、简体中文、繁体中文、西班牙语、葡萄牙语、俄语、日语、韩语、德语、法语、意大利语、印地语、阿拉伯语、土耳其语、越南语、印尼语、波兰语、泰语、荷兰语、瑞典语、捷克语、希伯来语、乌克兰语、罗马尼亚语、希腊语、匈牙利语、丹麦语和芬兰语。
```

## 更新说明

```
• 界面现已支持 28 种语言，包括繁体中文、阿拉伯语和希伯来语。
• 语言菜单现在可以搜索，也可以选择跟随系统语言。

```

## 功能

```
• 通过 WASAPI 环回捕获系统音频
• 支持 USB 与 Wi-Fi ADB 连接
• 自动重连上次使用的设备
• 手机端无需安装任何配套应用
• 界面支持 28 种语言
```
