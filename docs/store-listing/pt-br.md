# pt-br

## Nome

```
AudioShare
```

## Descrição

```
O AudioShare transmite o som do seu Windows ou Mac para um celular Android por USB ou Wi-Fi. Nada é instalado no celular e root não é necessário.

O computador captura o áudio; o celular reproduz.

Como começar
1. Instale o AudioShare no seu PC e abra-o.
2. Ative a depuração USB no celular, ou pareie com ADB via Wi-Fi, e conecte-o.
3. Toque em Conectar quando o celular aparecer na lista.

Tudo o que estiver tocando no seu computador agora sai pelo celular.

• Captura do áudio do sistema — 48 kHz estéreo no Windows (WASAPI loopback) e no macOS 13 ou posterior (ScreenCaptureKit).
• Nada para instalar no celular — o ADB e o servidor de reprodução já vêm dentro do AudioShare.
• USB e ADB via Wi-Fi, com reconexão automática ao último dispositivo usado.
• Privado por padrão — nada é gravado, armazenado ou enviado.

Requisitos
• Windows 10/11 x64 com drivers ADB funcionando, ou macOS 13 ou posterior.
• Um celular ou tablet Android com depuração USB ativada. Android 6.0 ou posterior.

O AudioShare está disponível em 28 idiomas: inglês, chinês simplificado, chinês tradicional, espanhol, português, russo, japonês, coreano, alemão, francês, italiano, híndi, árabe, turco, vietnamita, indonésio, polonês, tailandês, neerlandês, sueco, tcheco, hebraico, ucraniano, romeno, grego, húngaro, dinamarquês e finlandês.
```
