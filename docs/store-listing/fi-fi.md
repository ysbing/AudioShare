# fi-fi

## Näyttönimi

```
AudioShare
```

## Kuvaus

```
AudioShare siirtää Windows- tai Mac-tietokoneesi äänen Android-puhelimeen USB- tai Wi-Fi-yhteyden kautta. Puhelimeen ei tarvitse asentaa mitään, eikä root-oikeuksia tarvita.

Tietokone tallentaa äänen, puhelin soittaa sen.

Näin pääset alkuun
1. Asenna AudioShare tietokoneeseen ja käynnistä se.
2. Ota puhelimessa USB-virheenskorjaus käyttöön tai yhdistä se ADB:n yli Wi-Fissä, ja kytke se sitten.
3. Paina Yhdistä, kun puhelin näkyy luettelossa.

Kaikki, mitä tietokoneellasi soi, kuuluu nyt puhelimesta.

• Järjestelmän äänen tallennus — 48 kHz stereo Windowsissa (WASAPI loopback) ja macOS 13:ssa tai uudemmissa (ScreenCaptureKit).
• Puhelimeen ei asenneta mitään — ADB ja toistopalvelin tulevat AudioSharen mukana.
• USB ja ADB Wi-Fin yli, ja yhteys palautuu automaattisesti viimeksi käytettyyn laitteeseen.
• Yksityisyys etusijalla — mitään ei nauhoiteta, tallenneta eikä lähetä.

Vaatimukset
• Windows 10/11 x64 toimivilla ADB-ajureilla tai macOS 13 tai uudempi.
• Android-puhelin tai -tabletti, jossa USB-virheenskorjaus on käytössä. Android 6.0 tai uudempi.

AudioShare on saatavilla 28 kielellä: englanti, yksinkertaistettu kiinalainen, perinteinen kiinalainen, espanja, portugali, venäjä, japani, korea, saksa, ranska, italia, hindi, arabia, turkki, vietnam, indonesianmalainen, puola, thai, hollanti, ruotsi, tšekki, heprea, ukraina, romania, kreikka, unkari, tanska ja suomi.
```

## Mitä uutta

```
• Käyttöliittymä on nyt saatavilla 28 kielellä, mukaan lukien perinteinen kiinalainen, arabia ja heprea.
• Kielivalikkoa voi nyt hakea, ja se voi seurata järjestelmän ilmoittamaa kieltä.
• Asettelu skaalautuu nyt ikkunan mukaan sen sijaan, että oletettaisiin kiinteä koko.
```
