## שם לתצוגה

```
AudioShare
```

## תיאור

```
‏AudioShare מעביר את הצליל ממחשב Windows או Mac לטלפון Android דרך USB או Wi-Fi. אין צורך להתקין דבר בטלפון, ולא נדרש root.

המחשב מקליט את השמע; הטלפון משמע אותו.

מתחילים
1. מתקינים את AudioShare במחשב ומפעילים אותו.
2. מפעילים ניפוי שגיאות USB בטלפון, או משייכים אותו דרך ADB over Wi-Fi, ואז מחברים.
3. לוחצים על התחבר כשהטלפון מופיע ברשימה.

כל מה שמתנגן במחשב נשמע עכשיו מהטלפון.

• הקלטת שמע מערכת — 48 kHz סטריאו ב-Windows (WASAPI loopback) וב-macOS 13 ואילץ (ScreenCaptureKit).
• אין מה להתקין בטלפון — ADB ושרת ההשמעה כבר בתוך AudioShare.
• USB ו-ADB דרך Wi-Fi, עם התחברות חוזרת אוטומטית למכשיר ששימש לאחרונה.
• פרטיות קודמת — שום דבר לא מוקלט, לא נשמר ולא נשלח.

דרישות
• Windows 10/11 x64 עם מנהלי ההתקנים של ADB תקינים, או macOS 13 ואילץ.
• טלפון או טאבלט Android עם ניפוי שגיאות USB מופעל. Android 6.0 ואילץ.

‏AudioShare זמין ב-28 שפות: אנגלית, סינית פשוטה, סינית מסורתית, ספרדית, פורטוגזית, רוסית, יפנית, קוריאנית, גרמנית, צרפתית, איטלקית, הינדית, ערבית, טורקית, וייטנאמית, אינדונזית, פולנית, תאית, הולנדית, שוודית, צ׳כית, עברית, אוקראינית, רומנית, יוונית, הונגרית, דנית ופינית.
```
