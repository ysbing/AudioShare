# cs-cz

## Zobrazovaný název

```
AudioShare
```

## Popis

```
AudioShare přenáší zvuk z počítače s Windows nebo Mac do telefonu s Androidem přes USB nebo Wi-Fi. Na telefonu se nic neinstaluje a není potřeba root.

Počítač zvuk zachycuje, telefon ho přehrává.

Jak začít
1. Nainstalujte AudioShare do počítače a spusťte ho.
2. Na telefonu zapněte ladění USB nebo ho spárujte přes ADB přes Wi-Fi a pak ho připojte.
3. Když se telefon objeví v seznamu, stiskněte Připojit.

Vše, co na počítači hraje, teď zní z telefonu.

• Zachytávání systémového zvuku — 48 kHz stereo ve Windows (smyčka WASAPI) a v macOS 13 nebo novějším (ScreenCaptureKit).
• Na telefonu se nic neinstaluje — ADB i přehrávací server jsou uvnitř AudioShare.
• USB a ADB přes Wi-Fi, s automatickým připojením k naposledy použitému zařízení.
• Soukromí na prvním místě — nic se nenahrává, neukládá ani neodesílá.

Požadavky
• Windows 10/11 x64 s funkčními ovladači ADB nebo macOS 13 nebo novější.
• Telefon nebo tablet s Androidem se zapnutým laděním USB. Android 6.0 nebo novější.

AudioShare je dostupný v 28 jazycích: angličtina, zjednodušená čínština, tradiční čínština, španělština, portugalština, ruština, japonština, korejština, němčina, francouzština, italština, hindi, arabština, turečtina, vietnamština, indonéština, polština, thajština, nizozemština, švédština, čeština, hebrejština, ukrajinština, rumunština, řečtina, maďarština, dánština a finština.
```
