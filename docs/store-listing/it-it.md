# it-it

## Nome

```
AudioShare
```

## Descrizione

```
AudioShare trasmette l'audio del tuo Windows o Mac a un telefono Android via USB o Wi-Fi. Sul telefono non si installa nulla e non serve il root.

Il computer acquisisce l'audio; il telefono lo riproduce.

Come iniziare
1. Installa AudioShare sul PC e avvialo.
2. Attiva il debug USB sul telefono, oppure associalo in ADB via Wi-Fi, poi collegarlo.
3. Premi Connetti quando il telefono compare nell'elenco.

Tutto ciò che suona sul computer ora esce dal telefono.

• Acquisizione dell'audio di sistema — 48 kHz stereo su Windows (WASAPI loopback) e su macOS 13 o successivo (ScreenCaptureKit).
• Niente da installare sul telefono: ADB e il server di riproduzione sono già dentro AudioShare.
• USB e ADB via Wi-Fi, con riconnessione automatica all'ultimo dispositivo usato.
• Privacy prima di tutto: nulla viene registrato, archiviato o caricato.

Requisiti
• Windows 10/11 x64 con driver ADB funzionanti, oppure macOS 13 o successivo.
• Un telefono o tablet Android con debug USB attivo. Android 6.0 o successivo.

AudioShare è disponibile in 28 lingue: inglese, cinese semplificato, cinese tradizionale, spagnolo, portoghese, russo, giapponese, coreano, tedesco, francese, italiano, hindi, arabo, turco, vietnamita, indonesiano, polacco, thai, olandese, svedese, ceco, ebraico, ucraino, rumeno, greco, ungherese, danese e finlandese.
```
