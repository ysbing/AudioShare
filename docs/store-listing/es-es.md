# es-es

## Nombre

```
AudioShare
```

## Descripción

```
AudioShare transmite el sonido de tu Windows o Mac a un teléfono Android por USB o Wi-Fi. No se instala nada en el teléfono y no hace falta root.

El ordenador captura el audio; el teléfono lo reproduce.

Cómo empezar
1. Instala AudioShare en tu PC y ábrelo.
2. Activa la depuración USB en el teléfono, o empárejaselo con ADB por Wi-Fi, y conéctalo.
3. Pulsa Conectar cuando el teléfono aparezca en la lista.

Todo lo que suene en tu ordenador ahora sale por el teléfono.

• Captura del audio del sistema: 48 kHz estéreo en Windows (WASAPI loopback) y en macOS 13 o posterior (ScreenCaptureKit).
• Nada que instalar en el teléfono: ADB y el servidor de reproducción vienen dentro de AudioShare.
• USB y ADB por Wi-Fi, con reconexión automática al último dispositivo que usaste.
• Privado por diseño: no se graba, no se almacena y no se sube nada.

Requisitos
• Windows 10/11 x64 con controladores ADB en funcionamiento, o macOS 13 o posterior.
• Un teléfono o tablet Android con depuración USB activada. Android 6.0 o posterior.

AudioShare está disponible en 28 idiomas: inglés, chino simplificado, chino tradicional, español, portugués, ruso, japonés, coreano, alemán, francés, italiano, hindi, árabe, turco, vietnamita, indonesio, polaco, tailandés, neerlandés, sueco, checo, hebreo, ucraniano, rumano, griego, húngaro, danés y finitís.
```
