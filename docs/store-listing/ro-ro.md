# ro-ro

## Nume afișat

```
AudioShare
```

## Descriere

```
AudioShare transmite sunetul computerului tău Windows sau Mac către un telefon Android prin USB sau Wi-Fi. Nu trebuie să instalezi nimic pe telefon și nici nu este nevoie de root.

Calculatorul captează sunetul; telefonul îl redă.

Cum începi
1. Instalează AudioShare pe calculator și pornește-l.
2. Activează depanarea USB pe telefon sau îl împerechezi prin ADB pe Wi-Fi, apoi conectează-l.
3. Apasă Conectare când telefonul apare în listă.

Tot ce se auzea pe calculatorul tău iese acum din telefon.

• Captură de sunet de sistem — 48 kHz stereo pe Windows (buclă WASAPI) și pe macOS 13 sau mai nou (ScreenCaptureKit).
• Nu instalezi nimic pe telefon — ADB și serverul de redare sunt deja în interiorul AudioShare.
• USB și ADB prin Wi-Fi, cu reconectare automată la ultimul dispozitiv folosit.
• Confidențialitate înainte de toate — nu se înregistrează, nu se stochează și nu se trimite nimic.

Cerințe
• Windows 10/11 x64 cu drivere ADB funcționale sau macOS 13 sau mai nou.
• Un telefon sau tabletă Android cu depanarea USB activată. Android 6.0 sau mai nou.

AudioShare este disponibil în 28 de limbi: engleză, chineză simplificată, chineză tradițională, spaniolă, portugheză, rusă, japoneză, coreeană, germană, franceză, italiană, hindi, arabă, turcă, vietnameză, indoneziană, poloneză, thailandeză, olandeză, suedeză, cehă, ebraică, ucraineană, română, greacă, maghiară, daneză și finlandeză.
```
