# ru-ru

## Название

```
AudioShare
```

## Описание

```
AudioShare передаёт звук вашего Windows или Mac на Android-смартфон по USB или Wi-Fi. На телефон ничего устанавливать не нужно, root не требуется.

Компьютер захватывает звук, а телефон воспроизводит его.

Как начать
1. Установите AudioShare на компьютер и запустите его.
2. Включите отладку по USB на телефоне или сопоставьте его с ADB по Wi-Fi, затем подключите.
3. Нажмите «Подключить», когда телефон появится в списке.

Всё, что звучит на компьютере, теперь выходит через телефон.

• Захват системного звука — 48 кГц стерео в Windows (WASAPI loopback) и в macOS 13 и новее (ScreenCaptureKit).
• На телефон ничего не ставится — ADB и сервер воспроизведения уже внутри AudioShare.
• USB и ADB по Wi-Fi, с автоматическим переподключением к последнему устройству.
• Конфиденциальность по умолчанию — ничего не записывается, не хранится и не отправляется.

Требования
• Windows 10/11 x64 с рабочими драйверами ADB или macOS 13 и новее.
• Android-смартфон или планшет с включённой отладкой по USB. Android 6.0 и новее.

AudioShare говорит на 28 языках: английский, упрощённый китайский, традиционный китайский, испанский, португальский, русский, японский, корейский, немецкий, французский, итальянский, хинди, арабский, турецкий, вьетнамский, индонезийский, польский, тайский, нидерландский, шведский, чешский, иврит, украинский, румынский, греческий, венгерский, датский и финский.
```
