# ko-kr

## 표시 이름

```
AudioShare
```

## 설명

```
AudioShare는 Windows나 Mac의 시스템 소리를 USB 또는 Wi-Fi를 통해 안드로이드 휴대전화로 전달합니다. 휴대전화에는 아무 앱도 설치할 필요가 없고 루트 권한도 필요 없습니다.

컴퓨터가 소리를 캡처하고, 휴대전화가 재생합니다.

시작하기
1. PC에 AudioShare를 설치하고 실행합니다.
2. 휴대전화에서 USB 디버깅을 켜거나 ADB over Wi-Fi로 페어링한 다음 연결합니다.
3. 목록에 휴대전화가 나타나면 연결을 누릅니다.

컴퓨터에서 재생되는 모든 소리가 이제 휴대전화에서 나옵니다.

• 시스템 오디오 캡처 — Windows에서는 WASAPI 루프백으로 48 kHz 스테레오, macOS 13 이상에서는 ScreenCaptureKit을 사용합니다.
• 휴대전화 설치 불필요 — ADB와 재생 서버가 AudioShare에 함께 들어 있습니다.
• USB와 ADB over Wi-Fi를 지원하며 마지막으로 사용한 기기에 자동으로 다시 연결합니다.
• 개인정보 보호 — 녹음, 저장, 업로드를 하지 않습니다.

요구 사항
• Windows 10/11 x64(정상 작동하는 ADB 드라이버) 또는 macOS 13 이상.
• USB 디버깅이 켜진 Android 휴대전화 또는 태블릿. Android 6.0 이상.

AudioShare는 28개 언어를 지원합니다: 영어, 중국어 간체, 중국어 번체, 스페인어, 포르투갈어, 러시아어, 일본어, 한국어, 독일어, 프랑스어, 이탈리아어, 힌디어, 아라비아어, 터키어, 베트남어, 인도네시아어, 폴란드어, 태국어, 네덜란드어, 스웨덴어, 체코어, 히브리어, 우크라이나어, 루마니아어, 그리스어, 헝가리어, 덴마크어, 핀란드어.
```

## 새로운 기능

```
• 이제 28개 언어로 이용할 수 있습니다. 중국어 번체, 아라비아어, 히브리어 등을 포함합니다.
• 언어 선택 메뉴에서 검색할 수 있고, 시스템 언어에 맞춰 자동으로 따라갈 수도 있습니다.
• 레이아웃이 고정 크기를 가정하지 않고 창 크기에 맞춰 조정됩니다.
```
