# el-gr

## Εμφανιζόμενο όνομα

```
AudioShare
```

## Περιγραφή

```
Το AudioShare μεταφέρει τον ήχο του Windows ή του Mac σας σε ένα τηλέφωνο Android μέσω USB ή Wi-Fi. Δεν χρειάζεται να εγκαταστήσετε τίποτα στο τηλέφωνο, και δεν χρειάζεται root.

Ο υπολογιστής κάνει τη λήψη του ήχου, το τηλέφωνο τον παίζει.

Πώς ξεκινάτε
1. Εγκαταστήστε το AudioShare στον υπολογιστή σας και ξεκινήστε το.
2. Ενεργοποιήστε την αντιμετώπιση σφαλμάτων USB στο τηλέφωνο, ή συνδέστε το μέσω ADB over Wi-Fi, και μετά συνδέστε το.
3. Πατήστε Σύνδεση όταν εμφανιστεί το τηλέφωνο στη λίστα.

Ό,τι παίζει τώρα ο υπολογιστής σας ακούγεται από το τηλέφωνο.

• Λήψη ήχου συστήματος — 48 kHz στερεοφωνικό στα Windows (βρόχος WASAPI) και στα macOS 13 ή νεότερα (ScreenCaptureKit).
• Δεν χρειάζεται εγκατάσταση στο τηλέφωνο — το ADB και ο διακομιστής αναπαραγωγής περιλαμβάνονται στο AudioShare.
• USB και ADB μέσω Wi-Fi, με αυτόματη επανασύνδεση στη συσκευή που χρησιμοποιήσατε τελευταία.
• Ιδιωτικότητα πρώτα — τίποτα δεν ηχογραφείται, δεν αποθηκεύεται και δεν αποστέλλεται.

Απαιτήσεις
• Windows 10/11 x64 με λειτουργικά προγράμματα οδήγησης ADB ή macOS 13 ή νεότερο.
• Τηλέφωνο ή tablet με Android με ενεργοποιημένη αντιμετώπιση σφαλμάτων USB. Android 6.0 ή νεότερο.

Το AudioShare διατίθεται σε 28 γλώσσες: αγγλικά, απλοποιημένα κινεζικά, παραδοσιακά κινεζικά, ισπανικά, πορτογαλικά, ρωσικά, ιαπωνικά, κορεακά, γερμανικά, γαλλικά, ιταλικά, χίντι, αραβικά, τουρκικά, βιετναμέζικα, ινδονησιακά, πολωνικά, ταϊλανδικά, ολλανδικά, σουηδικά, τσεχικά, εβραϊκά, ουκρανικά, ρουμανικά, ελληνικά, ουγγρικά, δανικά και φινλανδικά.
```

## Τι νέο υπάρχει

```
• Η διεπαφή διατίθεται πλέον σε 28 γλώσσες, μεταξύ των οποίων τα παραδοσιακά κινεζικά, τα αραβικά και τα εβραϊκά.
• Το μενού επιλογής γλώσσας μπορεί πλέον να αναζητηθεί και μπορεί να ακολουθεί τη γλώσσα που αναφέρει το σύστημα.
• Η διάταξη κλιμακώνεται πλέον με το παράθυρο αντί να υποθέτει σταθερό μέγεθος.
```
