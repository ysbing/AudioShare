# uk-ua

## Відображувана назва

```
AudioShare
```

## Опис

```
AudioShare передає звук вашого Windows або Mac на Android-смартфон через USB або Wi-Fi. На телефон нічого встановлювати не потрібно, root не потрібен.

Комп'ютер захоплює звук, а телефон його відтворює.

Як почати
1. Установіть AudioShare на комп'ютер і запустіть його.
2. Увімкніть налагодження USB на телефоні або зв'яжіть його з ADB по Wi-Fi, а потім підключіть.
3. Натисніть «Підключити», коли телефон з'явиться у списку.

Усе, що звучить на комп'ютері, тепер чути з телефона.

• Захоплення системного звуку — 48 кГц стерео у Windows (WASAPI loopback) і в macOS 13 та новіших (ScreenCaptureKit).
• На телефон нічого не ставиться — ADB і сервер відтворення вже всередині AudioShare.
• USB і ADB по Wi-Fi, з автоматичним перепідключенням до останнього пристрою.
• Конфіденційність насамперед — нічого не записується, не зберігається і не надсилається.

Вимоги
• Windows 10/11 x64 зі справжніми драйверами ADB або macOS 13 та новіші.
• Android-смартфон або планшет з увімкненим налагодженням USB. Android 6.0 та новіші.

AudioShare доступний 28 мовами: англійська, спрощена китайська, традиційна китайська, іспанська, португальська, російська, японська, корейська, німецька, французька, італійська, гінді, арабська, турецька, в'єтнамська, індонезійська, польська, тайська, нідерландська, шведська, чеська, іврит, українська, румунська, грецька, угорська, данська та фінська.
```

## Що нового

```
• Інтерфейс тепер доступний 28 мовами, зокрема традиційною китайською, арабською та івритом.
• Вибір мови тепер можна шукати, і він може йти за мовою, яку вказує система.
• Макет тепер масштабується під вікно, а не орієнтується на фіксований розмір.
```
