# ja-jp

## 表示名

```
AudioShare
```

## 説明

```
AudioShare は Windows や Mac のシステムサウンドを、USB または Wi-Fi 経由で Android スマートフォンに転送します。スマートフォン側にアプリをインストールする必要はなく、root 権限も要りません。

PC が音声をキャプチャし、スマートフォンで再生されます。

はじめに
1. PC に AudioShare をインストールして起動します。
2. スマートフォンで USB デバッグを有効にするか、ADB over Wi-Fi でペアリングしてから接続します。
3. 一覧にスマートフォンが表示されたら「接続」を押します。

PC で鳴っている音が、スマートフォンから音として出ます。

• システムオーディオのキャプチャ — Windows では WASAPI ループバックで 48 kHz ステレオ、macOS 13 以降では ScreenCaptureKit に対応しています。
• スマートフォン側のインストールは不要 — ADB と再生サーバーは AudioShare に同梱されています。
• USB と ADB over Wi-Fi に対応し、前回使った端末へ自動的に再接続します。
• プライバシーを重視 — 録音も保存もアップロードも行いません。

動作環境
• Windows 10/11 x64（正常に動作する ADB ドライバー）または macOS 13 以降。
• USB デバッグを有効にした Android スマートフォンまたはタブレット。Android 6.0 以降。

AudioShare は 28 言語に対応しています：英語、簡体字中国語、繁体字中国語、スペイン語、ポルトガル語、ロシア語、日本語、韓国語、ドイツ語、フランス語、イタリア語、ヒンディー語、アラビア語、トルコ語、ベトナム語、インドネシア語、ポーランド語、タイ語、オランダ語、スウェーデン語、チェコ語、ヘブライ語、ウクライナ語、ルーマニア語、ギリシャ語、ハンガリー語、デンマーク語、フィンランド語。
```

## 新機能

```
• インターフェースが 28 言語に対応しました。繁体字中国語、アラビア語、ヘブライ語などを含みます。
• 言語メニューが検索できるようになり、システムの言語に追従させることもできます。
• レイアウトが固定サイズを前提にせず、ウィンドウに合わせて縮小・拡大するようになりました。
```

## 機能

```
• WASAPI ループバックによるシステム音声のキャプチャ
• USB と Wi-Fi 経由の ADB 接続
• 前回の使用端末への自動再接続
• スマートフォンにインストールするアプリは不要
• 28 言語のインターフェース
```
